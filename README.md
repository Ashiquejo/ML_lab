# 🚀 How to Run

Clone the repository

```bash
git clone https://github.com/Ashiquejo/ML_lab.git
```

Move into the project

```bash
cd ML_lab
```

Install dependencies

```bash
pip install numpy pandas matplotlib scikit-learn
```

Run any experiment

```bash
python Exp_1.py
```

or

```bash
python Exp_2.py
```
